# 音效卡顿补丁入口

“常见问题 → 补丁”新增第二项“音效卡顿补丁”，与“吃桃补丁”并排显示。悬停文案：“修复部分设备开启音效后在攻击、释放策略卡顿问题”。

点击打开确认弹窗，说明补丁是独立 EXE 启动器，需要使用补丁提供的 EXE 启动游戏才能生效。仅提供“使用补丁”“取消”。使用补丁把内置 `Ekd5-audio-fix.exe` 复制到所定位游戏 EXE 的目录，完成后显示启动器路径与启动方式；不会在安装时自动运行游戏。

资产逐字节来自用户提供的 `E:/game/ccz/曹操传加强版v2.20-1104夜/Ekd5-audio-fix.exe`，SHA-256 为 `5bb66f71f7641da63473f9cd730dfbc37886ac448657ae61e87fbc86da734b32`。启动器自带控制 DLL 资源。资源保存于 `resources/patches/Ekd5-audio-fix.exe`，并已加入正式 PyInstaller spec。安装时核对指纹，使用同目录临时文件写入后重命名；同版本重复安装直接提示准备完成，其他同名启动器不覆盖，写入失败清理临时文件。

安装不替换 `Ekd5.exe`，不更改吃桃补丁的 `CCZFX.DLL`，不修改存档。测试使用临时目录验证这几个文件的保留，不代表重新实测两种补丁在真实游戏运行中的组合效果。本轮不启动游戏，也未改动用户提供的源文件。

27 项针对性及相关界面测试通过，包括真实启动器载荷、复制失败清理、校验失败、重复安装、同名文件保护、缺少游戏、打包路径、真实 FAQ 两项补丁、精确悬停文案、弹窗两按钮、异步安装及取消。日志为 `artifacts/audio-patch-tests.log`。

使用项目虚拟环境重新构建，交付目录 `artifacts/dual-patch-release/`；打包后直接提取内置两个补丁，与资源文件逐字节核对。压缩包包含工具 EXE 与使用说明。
