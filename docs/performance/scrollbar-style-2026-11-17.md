# 应用内滚动条统一

## 视觉与范围

应用内横、纵向滚动条共用 ttk 主题：浅色无边框轨道、圆角灰色滑块，悬停加深、按下进一步加深。去掉两端箭头，保留拖动及点击轨道翻页；滚轮沿用各页面原有行为。宽度和滑块最小尺寸随 Tk 显示缩放计算。

统一覆盖历史记录及详情、规则设置与说明、人物列表、宝物、入队人员、兵种天赋、特效手册、统计图表与完整排行、使用说明和搜索下拉列表。主窗口输出、运行明细、评分详情、长消息、诊断报告及依赖提示中的 ScrolledText，也改用 ttk 滚动条；保留其文本编辑、只读及布局 API。

统计频率图内的滚动条另外调整了上下与右侧留白，图形内容按实际滚动条宽度预留位置。没有更多内容时，继续隐藏图内滚动条。

Windows 原生文件选择器和外部程序不属于应用控件，继续使用系统样式。

## 实现与性能

- `ui/scrollbars.py` 定义统一 ttk 元素，`ui/theme.py` 初始化一次，横纵向共享同一套配色。滑块图像仅初始化时创建并由 root 持有，滚动时不会重新生成。
- 继续使用 ttk 原有滚动条事件绑定；没有新增动画、轮询或逐帧回调。
- `ui/scrolled_text.py` 保留标准 ScrolledText 的接口，将其滚动条替换成 ttk 控件，集中覆盖原来容易遗漏的文本窗口。
