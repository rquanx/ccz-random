## 本轮改动

- 宝物静态段落改为复用的 Canvas 文本块，保留分类、组合、颜色、换行和所有条目。过滤不再销毁重建整块控件；清空搜索后复用原卡片。
- 整轮结果改为每张卡片一个绘制面，减少大量 Label/Frame 的创建、布局与销毁。
- 入队人员按完整数据计算布局并缓存文字尺寸，只绘制当前视口的行；滚动可以到达全部记录，保持关卡分组和特殊/高阶颜色。
- 143 人存档详情复用可见人物卡片，完整滚动范围保留；按真实字体和宽度计算行高，扩大/缩小窗口时重新计算，避免裁剪。
- 人物倾向关闭后复用窗口，重开重置取消的输入、应用最新配置和回调；规则说明页首次选择时创建。
- 搜索下拉框使用预处理索引及一次批量填充，等价查询保持原列表。最近搜索列表没有变化时保留现有按钮。
- 统计图表数据不变时不重复栅格化，频率数据不变时保留滚动位置。统计关闭后复用控件，重开重新读取数据；仓库初始化移到工作线程。
- 完整排行搜索去抖从 180ms 缩至 60ms，继续丢弃过期查询响应。
- 诊断的游戏定位和环境检查移至工作线程。声音修复的进程枚举和系统音频调用也在后台运行，防止重复提交；用户仍须先确认修复。
- 空间清理复用统一的 20ms 后台结果交付机制，扫描期间允许关闭窗口；不可中断的清理期间继续保护关闭操作。
- 首次须知和并发详情使用窗口所有的定时器，关闭时取消待执行回调。

## 测量边界

所有 UI 测试运行在独立 Windows 桌面，不切换用户桌面，不移动鼠标或键盘。实际 EXE 使用固定数据库副本及已确认的真实快照，声音、诊断兼容性测试、日志上传、文件选择和外链操作使用离线替身或取消路径。没有启动游戏、操作真实音频会话、发送日志、访问更新服务、改动真实存档/统计或写入首次阅读状态。

源码阶段的性能报告仅用于定位问题，不与 EXE 数值混作同一对照。最终 EXE 验证期间不并行运行构建和单元测试，不用空窗口出现代替数据就绪，不把缓存重开代替首次打开。私有桌面不能代替交互桌面的 DWM 帧率和游戏负载下的真实手感。

## 最终验证结果

- 完整单元测试：863 项通过，251.128 秒。
- 源码后台验证：172 个场景通过；仅作为定位与正确性验证，不作为 EXE 性能对照。
- 最终实际 EXE：三轮各 172 个场景全部通过，三份报告均为 `frozen=true`、`status=passed`、`callback_errors=[]`。构建自带的启动、窗口输出、导入及更新记录四项 EXE 冒烟也通过。
- 固定副本含 61 轮历史、4,150 次统计、356 项宝物效果统计和 204 项特技统计；另外覆盖已录制的 143 人存档快照。
- 以三轮每场景中位数统计：161 项低于 300ms，11 项超过 300ms；不能据此声称每轮每个操作都低于 300ms。各场景的最大心跳间隔取三轮中位数后，最大为 158.57ms。

### 与旧 EXE 的共同场景对照

旧 EXE 只内嵌 52 个场景，已同样跑三轮，并与新版交替串行运行。新增子窗没有旧 EXE 同口径数据，因此只报告新版绝对耗时。

| 操作 | 旧 EXE ms | 新 EXE ms |
| --- | ---: | ---: |

| 历史首次打开 | 518.90 | 555.72 |
| 历史详情（主入口） | 383.80 | 324.24 |
| 历史销毁后重建 | 547.80 | 505.63 |
| 历史关闭后复用重开 | 196.08 | 181.77 |
| 规则首次打开 | 325.51 | 334.87 |

这轮主要补齐子窗的全量控件创建、重复绘制、窗口复用和阻塞调用问题，不能解释为所有路径都变快。统计首次、历史首次和规则首次的三轮中位数仍高于旧版；这些冷启动路径尚未达标。心跳间隔与内容就绪耗时分别记录，后台读取期间界面可响应也不等于数据已经显示。
