# 吃桃补丁安装与还原

入口为“常见问题 → 补丁 → 吃桃补丁”。悬停说明支持高编号人物吃桃、喝酒；点击打开确认窗口，显示将替换的 EXE、目录、实验性质、备份名称与还原范围。提供“使用补丁”“还原”“取消”，默认不执行文件操作。

补丁资产为 `resources/patches/growth-fix.zip`，包含此前实测的 `Ekd5.exe`、`CCZFX.DLL` 和 UTF-8 说明文档；正式工具的 PyInstaller spec 已加入此资源。EXE 和 DLL 在写盘前分别校验补丁载荷的 SHA-256；不校验目标游戏版本或目标 EXE 指纹，适用性由用户自行判断。

安装前先停止随机、关闭游戏。后台工作线程读取校验补丁并在游戏目录暂存，然后将原 EXE 重命名为 `Ekd5.peach-backup.exe`，安装 DLL，最后替换 EXE。已有备份不覆盖，重复安装提示已安装，未知 CCZFX.DLL 不覆盖；安装异常恢复原 EXE 并清除本次新增 DLL 和临时文件。操作期间禁用按钮与关闭，避免在事务中途取消。

还原定位同目录的 `Ekd5.peach-backup.exe`，替换当前 EXE；没有备份时提示“没有可以还原的 EXE”。当前 EXE 丢失时也能从备份恢复。还原不校验备份版本或当前 EXE 指纹，直接恢复该目录的备份。还原后备份已移回 EXE；CCZFX.DLL 保留，原 EXE 不加载它。

安装与还原均不修改存档。还原不恢复已发生变化的存档或人物成长；原版 EXE 不识别高编号额外成长的限制仍适用，详见原型测试文档。

安装服务和真实 Tk 弹窗测试使用真实已验证补丁文件、临时目录及私有测试桌面，不启动游戏。覆盖首次安装、文件内容、备份、还原、无备份、重复安装、不同版本 EXE 的安装还原、不同指纹备份的还原、其他 DLL、后续 EXE 修改后的还原、复制失败回滚、真实 FAQ 入口／悬浮提示／三按钮、运行中阻止操作及打包资源路径。
