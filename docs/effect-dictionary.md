# 特效手册维护说明

字典适用于 `ccz-v2.20-1104-night`。界面只显示特效名称和效果说明，资料证据保留在资源与本文中。

## 按特效编号整理宝物效果

当前99项宝物效果使用独立的说明，不再自动套用同名人物特技。作者输入为 `tools/research/data/equipment_effects_1104.json`，提取脚本将它与特技说明合并为运行时资源 `resources/data/effects/ccz-v2.20-1104-night.json`。

原始物品表来自已捕获的本版游戏内存：表地址 `0x4A1140`，每条25字节，名称从记录起始处读取。武器、防具的效果编号在偏移20，辅助装备的效果编号在偏移17；偏移20为2时按辅助装备解释。物品对应的 `Imsg.e5` 说明记录为 `1946 + 物品索引`。73个特效编号可以通过原始物品直接对应说明；资源保留原始25字节、物品名和说明记录号，可复核对应关系。这里读取的是原始配置，不是已经随机的存档。

例如：

- 昭威奋烈：原始雌雄双剑，反击后再反击、每回合首次攻击伤害变为1。
- 百战不殆：原始白帝剑、孙子兵法，按自身和敌人等级附加、减少物理及策略伤害。
- 辅爆强连：原始飞龙斗袍、乌油甲，同时提高爆发力和连击率。
- 破甲攻击：原始流星锤、手戟，按最大HP比例造成伤害并必中，不能套用人物同名特技的“固定值伤害”。
- 限制伤害：原始国士无双袍，采用宝物参数上限，不能套用人物攻击限伤的固定70点。

补充说明通过独立特技说明、游戏更新说明和原生查询函数对应：`0x4101D9` 的前两个参数是人物特技编号、装备效果编号。增伤强命的三个查询位于 `0x421123`、`0x421135`、`0x43B698`，分别关联突破攻击、伤害增幅、辅助攻击命中。其他查询包括削铁如泥ALL、盾反、状态强化、策略免疫、弱点攻击。元数据中的 `skillHelp` 保留相关独立说明编号，`nativeCalls` 仅记录已解码的调用地址。

中毒破士、封策破精、步兵克制、骑马克制四项未在本版原始物品中出现，仅按特效名称展开基本含义，不补写未知的概率、倍率或组合计算方式；以 `basis: literal-effect-label` 标记供维护时区分。这四项未做战斗实测，不能将名称语义展开解释为机制验证完成。

## 独立特技说明

`Imsg.e5` 每条200字节，GBK编码，第 `430 + skillId` 条对应本版 runtimeCatalog，第670条起不再是特技说明。原始240条资料保留在资源中，空说明、占位符、玩笑或注明不可用的条目不进入查询列表，最终显示226条有内容的特技说明。

固定来源哈希：

- Ekd5.exe：`aece85339ff48c24e8d783d2d65766e8c9f7be00bd7389d38a8cad8f7cbd95a5`
- Imsg.e5：`a29c01b83cbc5b1bc9a1f0f071b9f9480a91f7673ce50b618d91de5a932941f9`

“穿越偷袭”的组合定义来自 UTF-8 更新说明：“1.穿越移动→穿越偷袭=穿越移动+偷袭攻击。”，分别结合穿越移动和偷袭攻击的独立说明。迅捷之勇新增破坏移动等修订也以本版更新说明为准。

## 生成与版本匹配

```powershell
.venv-win10-py314/Scripts/python.exe tools/research/extract_effect_dictionary.py '<游戏目录>'
```

生成脚本校验程序和说明表哈希、原始物品效果编号、说明记录及99项覆盖情况。运行时绑定profileId、gameVersion，以及runtimeCatalog与宝物显示规则的联合哈希；热更新改变相关资料时停止复用旧字典。仅修订号变化、相关资料不变时可继续使用。查询不读取当前游戏存档、不修改战斗或随机逻辑。

## 同效果条目合并

`effect_dictionary_merge.py` 维护人工核对的23组等价关系，合并名称、原名别名和参数搜索表达式，不使用模糊名称或文本相似度推断等价。削铁如泥ALL统一显示为削铁如泥。保留源条目ID与分类，便于追溯。共325条资料显示为302项。

破甲攻击、MP防御、引导攻击、主动连击、迅捷之勇等存在额外触发条件或效果，保留独立说明并标明宝物/特技。同类能力组合或范围不同的特技也继续保留。

## 特效模仿解析修正

宝物特效编号 `0x74`（116）对应“特效模仿”，不是参数为3的数值效果。用户截图中的风车轮 `0x74/0x03` 应显示“特效模仿”。游戏原生宝物名称查询 `0x4230D5` 经编号减去 `0x1A`、扩展表偏移 `0x3C` 后，读取 `[0x5003F8 + 30×4] = 0x4CE104`，GBK字节为 `ccd8d0a7c4a3b7c2`；后缀分派表 `0x462309 + (0x74 - 0x1A)` 为0，不附加参数。独立说明第518条说明周围四格、装备/个人/兵种特效、不分敌我及部分特效无法模仿。内置数据包修订号升至r6，同时更新特效手册绑定哈希。

首次修正的回归测试覆盖截图参数、全部256种参数及已有真实宝物采样编号，随后补充下述全表检查。原来的测试只比较说明表与解析表，无法发现两边同时漏项。

## 原生宝物编号完整性

新增 `tests/fixtures/equipment_native_1104.json`，从同一哈希的游戏内存独立提取 `0x1A` 至 `0x7C` 的99项原生名称及参数后缀分派类型。完整性测试遍历99×256组编号和参数，新增12项逐一与原生后缀分派规则核对。众矢之的按参数低两位选择空、攻击、策略、ALL，不将原始参数当作百分比。lookup类手册名称从各自模板提取，避免把众矢之的误标为穿透攻击。

新补录12项的名称和参数格式已有原生表证据；机制说明仅按名称展开基本含义，以 `basis: literal-effect-label` 标记，不补写未经战斗验证的触发范围、概率和计算公式。众矢之的当前仅说明参数类别，不断言具体战斗机制。99项覆盖限定于本版原生宝物表，不代表其他版本或扩展编号。此前采样编号测试保留为补充，不再作为完整性依据。
