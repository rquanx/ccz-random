# C# WPF 迁移

`src/CczRandomizer.Wpf` 是 2.2 版本的 C# WPF 迁移工程，目标框架为 `net10.0-windows`。

当前阶段已完成：

- WPF 主窗口和统一窗口居中行为；
- 随机运行、规则设置、历史记录、常见问题四个主入口；
- 读取游戏目录中的 `random_rules_v2.json`；
- 展示当前规则、参与人物、兵种门槛和规则模式；
- Release 构建验证。

迁移顺序按依赖关系推进：

1. 规则模型与编辑器；
2. 存档、内存读取和沙箱生命周期；
3. 随机运行与评分流程；
4. 历史记录、详情卡片和空间清理；
5. 独立发布 EXE 并替换旧入口。

迁移期间 Python 版本继续作为行为基准，直到 WPF 版本覆盖完整流程后再切换默认发布入口。
