# 页面与子弹窗性能再次复核

## 范围和计时

沿用 [窗口族与交互清单](all-dialog-interactions-performance-2026-11-17.md)，检查主界面入口、各级子窗、页签、翻页、筛选、滚动、关闭及复用。新增兵种天赋的特殊技能、高阶兵种勾选和恢复场景。300ms 是操作到内容就绪的目标，另记录界面事件循环的最大心跳间隔；窗口先出现或后台读取没有阻塞，均不能替代内容已经可用。

实际 EXE 在私有 Windows 桌面串行测量，数据库来自游戏目录的 SQLite 一致性副本，143 人详情使用已录制的真实快照。测试不切换用户桌面，不占用鼠标键盘，不改真实游戏、历史或统计数据。维护、上传、声音修复等外部操作使用离线替身或取消路径。

## 本次调整

- 通用窗口先在隐藏状态协商尺寸、按屏幕工作区居中，然后显示，避免先映射透明窗口再反复布局绘制。保留外框尺寸、负坐标、多屏 DPI 修正和失败后的可见性兜底。
- 通用可见卡片由每张一次定时器改为每批最多四张、最多约 6ms 的工作预算。调整尺寸时也分批重排，继续释放离屏卡片、复用控件并保持完整滚动范围。
- 历史轮次和整轮结果使用相同的小批量预算，减少 Windows 短定时器粒度带来的串行等待。
- 人物详情合并同一轮几何协商的中间宽度，等真实宽度确定后再测量，不先按猜测宽度计算整份数据；卡片按最终宽度直接绘制一次，并把绘制工作计入分批预算。按文字、字体实际属性、缩放和换行宽度缓存尺寸，最多 4,096 项，避免跨窗口复测相同文字。延后测量的定时器随窗口关闭取消。
- 静态段落内容不变时保留绘制结果；仅宽度改变时不重复设置文字、字体和颜色。
- 完整统计排行由三次相同的 SQL 聚合改为一次，仍由 SQLite 保持字面搜索和排序规则，再从不同标签的聚合结果计算总数及分页。不会将全部原始观测加载到内存，也不引入可能过期的观测缓存。
- 后台任务没有请求或订阅时停止轮询；新任务、进度订阅自动恢复。单次结果交付限制为最多 64 项或约 8ms，保留消息顺序，过期响应继续丢弃，避免进度突发占住界面线程。
- 宝物、兵种天赋、入队人员、特效手册、统计窗口的销毁订阅只接收窗口自身事件，避免子控件销毁时反复跨 Tcl/Python 分发无效回调。

临时比较过去掉透明属性和切换 `clam` 主题，没有取得稳定改善，未纳入产品修改。保留现有 ttk 风格与全部数据展示。

## 回归保障

新增回归验证：可见行在滚动、调整尺寸、更换数据后保持正确；真实 143 人数据在多个宽度下不裁剪；尺寸缓存有上限；空闲轮询停止后能恢复任务及订阅；旧订阅不能发布过期结果；300 条突发进度保序、不丢消息，并允许界面事件插入处理。窗口居中测试另外验证首次定位确实发生在隐藏状态。

继续运行历史延迟读取与取消、完整人物与宝物内容、规则编辑、统计筛选与分页、维护窗口生命周期、负坐标屏幕、DPI 和定位失败兜底等既有回归。

## 测量限制

原生文件选择器、外部浏览器、实际网络服务、真实游戏随机和音频会话自身耗时未纳入 UI 性能结论。私有桌面能验证真实 EXE 的控件构建、数据就绪和事件循环阻塞，但不能代表用户交互桌面的 DWM 帧率、游戏负载或所有分辨率的手感。构建、单元测试和性能对照分阶段执行，最终性能测量不与其他测试并行。

## 实际 EXE 三轮结果

旧版每轮 175 项，新版每轮 179 项（增加四项兵种天赋筛选/恢复），三轮全部通过，均为 `frozen=true`、`callback_errors=[]`。六轮均验证为 61 轮历史、4,150 次统计，使用相同来源的真实 143 人快照。

143 人详情的总就绪时间没有实质改善（692.19→694.99ms），但其最大心跳间隔中位数从 188.67ms 降为 114.14ms。新一轮源码剖析确认布局阶段仍给出两个中间宽度，因此最后合并该轮测量并在渲染预算内直接绘制卡片；三轮结果来自这份最终 EXE。不会把界面较少阻塞等同于详情已经显示。

剩余慢项主要集中在较大窗口的首次控件创建、文字布局和 Windows/Tk 首帧绘制；历史页还包括后台读取后可见结果的生成。逐人详情虽然仅创建可见卡片，为保证完整滚动范围及不裁剪，仍需计算全部人物行高。当前修改减少重复工作并控制单次占用，没有消除这些成本。进一步压到 300ms 需要继续减少原生绘制面、分段/增量测量和重构详情布局，不能靠缩短轮询或隐藏加载提示达成。
