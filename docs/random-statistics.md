# 数据统计

主界面“历史记录”旁的“数据统计”可独立打开，无需启动游戏。
支持开始、结束时间、规则、人物和结果组合筛选，筛选项位于同一行。日期可以填写
`YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM[:SS]`；结束日期包含当天，
结束时间包含填写的那一分钟或一秒。日期输入后按回车或点击刷新。
刷新会同时更新规则和人物选项、读取最新已落库的采集批次。

## 图表与口径

- 结果可选“全部结果”“只看合格”“只看不合格”，所有指标和图表同步筛选。
  “合格”以规则检查通过为准，包括合格后保存失败的执行；
  “不合格”只包含兵种淘汰和特技淘汰，异常、停止和检查未完成不会被当成不合格。
  “全部结果”保留这些其他状态。

- 过程总览：执行次数、规则合格数、实际保存数、合格比例、平均执行耗时；
  环形图展示执行结果构成，折线图展示每日执行与保存趋势，横条图展示不合格原因和规则保存比例。
  每日趋势上下分图共用日期、各自使用独立的线性刻度，防止少量保存次数被大量执行次数压平；
  两图分别显示合计，真实零值明确标注，悬停日期所在列可查看执行与保存的完整数量。
  不合格原因使用简短标签；横条标签按实际显示宽度缩略，悬停标签或条形可查看完整名称和数量。
- 分数与人物：兵种、特技分数直方图，以及兵种、特技频率排行；
  悬停图形可查看完整名称和数值。分数按每组 1 分统计，含左端、不含右端。
- 兵种、特技和宝物效果频率卡片直接展示全部出现次数大于 0 的项目，按次数降序排列。
  可用卡片内滚轮、滚动条和名称搜索查看全部，无需“查看全部”或翻页。
  沿用当前时间、规则、人物和结果筛选；宝物效果还沿用宝物选择。
  只绘制可见行，滚动时保持统一的条形比例；切换筛选或搜索后返回列表顶部。
- 宝物效果页统计实际随机得到的效果，可选择全部宝物或指定一件宝物，
  效果文本中的参数保留，不把不同数值合并为同一项。
  每件宝物每次随机计一次，不重复计算套装或“好东西”等展示分组。
  人物筛选作用于该人物参与的随机，宝物不视为该人物的装备。
- 人物筛选后，总览表示“包含该人物观测数据的执行”，不表示失败仅由该人物造成；
  分布和频率只统计该人物。人物选项来自实际参与兵种或特技检查的人物。
- 兵种未通过时通常不会检查特技，未检查的数据不算作零分。
  图表分别显示已检查次数、已评分人次；特技频率按人物每次执行的出现次数计算，同名特技去重。
- 合格比例为规则合格数 / 执行次数，规则保存比例为实际保存数 / 执行次数。
  异常、停止、检查未完成均单列，不并入兵种或特技淘汰。
  一次执行可能有多个不合格原因，原因计数不可直接相加视作淘汰总数。
- 规则合格但保存失败不计入保存成功；保存后其他处理异常仍保留实际保存计数。
  保存后异常的执行归入异常，因而保存成功指标不一定等于环形图的保存成功分类。
- 平均执行耗时包含该次执行的读档、随机、检查和保存，不包含结果图片等后处理。
  恢复重试是独立执行，即使轮次、槽位、尝试编号相同也不会互相覆盖。
- 规则选项使用最新规则名称，不显示哈希后缀。名称、采集信息、结果图与编辑页签的变化不拆分统计关联。
- 保存时只有过滤条件实际变化才询问：确认覆盖、取消、保存为新规则。覆盖后，旧随机记录仍计入“全部规则”的所有相关统计，但不能再通过当前规则选项筛选；旧记录不会重新评分。另存为新规则会保留原规则及其统计关联。
- 取消或关闭窗口时，过滤条件有未保存修改会询问是否放弃，也可保存为新规则；只改名称或采集信息不弹出过滤条件变化警告。新建或删除规则尚未保存时仍询问是否放弃列表修改。

## 保存与性能

数据库为 `ccz_fast_data/statistics.sqlite3`，独立于历史记录。
统计库 v3 为宝物观测分配稳定整数编号，宝物名称和完整效果文本各保存一份；
逐次观测仍独立保留，参数不同的效果不会合并。旧库在事务内升级，失败回滚，完成后回收空闲页。
排行先按整数效果编号汇总，再读取效果文本，避免每条观测重复关联长文本。

历史库 v4 无损压缩完整结果快照和独立存档副本，卡片摘要仍直接读取；
详情和导出时还原，存档继续按原始 SHA-256 校验。旧快照和存档副本分批升级，
不删除记录、不减少采样，也不修改游戏目录中的原始存档或已导出的结果文件。
循环各轮、并发实例和没有生成合格结果的运行均可采集；删除历史记录不影响统计。
仅采集本功能启用后的实际执行，不能从已有成功历史反推过去的淘汰次数。

评分采集复用现有规则评价详情。宝物效果在随机完成、规则筛选之前增加一次只读内存快照，
使兵种或特技淘汰的结果也可统计宝物效果；采样失败记录诊断日志，不阻断筛选和保存。
统计快照与合格后保存、详情展示的宝物读取分开，避免影响现有结果。
宝物统计仅包含实际采集到的样本，界面标明采集次数；旧统计数据升级后不推算宝物效果。
后台线程以至多 128 条一批写入，
界面通过独立后台任务读取，关闭窗口后不再更新控件。
多进程共用 WAL 数据库，通过事务提交；首次初始化遇到锁竞争时会重试。
正常退出会刷新剩余队列，强制终止进程可能丢失尚未落库的最后一批。
队列设有容量上限，存储故障不阻断随机和存档；可保存的缺失计数会在统计页提示，故障细节写入诊断日志。

图表使用 Tk Canvas 承载，图形以 3 倍分辨率绘制后通过 Lanczos 缩小，
改善圆环、折线、圆点和圆角条形的锯齿；文字保持原生绘制，悬停通过独立几何区域判断。
窗口缩放重绘合并至 50 毫秒，尺寸和数据不变时复用已绘制图像。
参考 TanStack Charts 的卡片层次、柔和蓝紫青色系和直接数值反馈，
无需额外浏览器或图表运行时。超过 60 个趋势采样点会合并相邻组的计数并在悬停提示显示范围；
频率列表没有前 12 项限制，不合格原因与规则保存比例仍显示前 12 项。

## 回归验证

`test_statistics` 验证真实规则评价格式的采集、兵种短路、特技淘汰、保存状态、
规则版本、时间边界、人物范围、循环轮次、恢复执行、重复提交、事务回滚、
多线程及多进程初始化和写入竞争、磁盘故障隔离。
`test_statistics_ui` 使用隐藏 Tk 窗口验证异步人物筛选、关闭清理、绘制复用、悬停交互和完整频率列表的筛选。
`test_statistics_frequency` 验证滚动可达最后一项、可见行绘制数量有界、滚动条比例固定、零次数过滤、局部滚轮及名称搜索。
`test_statistics_graphics` 验证抗锯齿边缘、圆环方向和空心区域、完整圆环及零宽条形。
`test_statistics_equipment` 使用真实随机后的 70 件宝物夹具，验证效果排行、单件宝物筛选、
全部正频率查询、排行分页和搜索、旧数据库升级、读取失败隔离及与原结果详情快照的分离。
快速测试不依赖真实游戏进程。

## 规则关联兼容

规则配置保存稳定的内部身份，用于在改名后继续关联历史；副本、导入和另存的新规则取得独立身份。过滤指纹排除名称、身份元数据、采集选项、结果图及编辑展示设置，并将显式默认评分与省略默认评分、整数与等值小数统一比较。旧数据库无需重写或删除：查询时按当前规则身份、旧名和过滤内容解析关联，只合并过滤条件一致的记录。每次确认覆盖都会开始新的统计关联，即使以后把过滤条件改回旧值，也不会重新关联旧记录。已覆盖、删除或无法匹配的记录仍留在全部统计中，不提供规则筛选项。规则保存后，已打开的统计窗口刷新最新名称并保留仍有效的选择。

过滤条件修改的保存及放弃确认不展示规则名称。仅当前被修改规则存在关联的实际观测记录时展示统计说明；其他规则的数据、没有观测的快照以及此前已断开关联的数据不触发说明。查询使用只读连接，不创建或升级统计数据库；已有数据库无法读取时明确提示未能核实关联，不将其当作没有数据。

`test_rule_statistics_identity` 使用真实默认规则、临时配置文件与 SQLite 验证覆盖后的全量保留、规则筛选隔离、旧快照合并、重命名、采集选项、另存身份及保存/取消三个分支。
