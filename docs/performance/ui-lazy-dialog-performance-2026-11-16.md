# 按需创建、视口列表和窗口复用

## 改动

- 简单模式首次打开时只创建简单表单，高级表单在首次选择高级模式时创建。高级模式中的兵种、特技评分页及实验功能页再按首次选择分别创建。配置数据和编辑控件分离，未打开的页面不应改变保存结果；仅浏览页面不触发过滤规则变更提示。
- 规则窗口关闭后保留控件；再次打开时使用调用方最新已保存配置重置表单，并替换保存回调。取消掉的输入、未提交的行内编辑和上次切换的规则不会作为新一轮编辑的起点。不同目录或不同兵种/特技目录会重建窗口。资料激活事件继续重建窗口，保证新目录生效。
- 历史结果只创建当前视口内的卡片，滚动时复用卡片，保留完整滚动范围和全部数据。独立视口控制器合并滚动通知，并在卡片之间让出事件循环；更换数据时取消旧的绘制任务。清空列表时恢复布局传播并重置滚动范围。
- 历史结果摘要按同一 Canvas 字体和换行宽度测量行高，避免虚拟列表裁掉人物内容或操作按钮。左侧轮次卡片合并为单个文字 Canvas，编辑操作继续使用原生 ttk 按钮与输入框；窗口缩放时重排文字。左侧每页最多十张，继续使用固定池复用，避免回翻时增加绘制调度。
- 历史窗口关闭后保留控件，再次打开重新查询数据并保留仍然有效的选择。关闭缓存窗口会销毁它的详情子窗和提示浮层，释放模态抓取；再次打开仍按所在屏幕工作区居中。

## 回归覆盖

新增检查：未打开的页面保存后配置不变；浏览高级页不算编辑；关闭并重新打开后使用最新配置、取消输入不残留、模态抓取正确释放和恢复；历史窗口重新打开能读取新记录；15 个结果均可滚动查看，末项能打开正确详情，卡片文字和按钮不被裁剪；轮次翻页仍编辑当前记录且复用的控件数量有界。

旧用例中依赖“关闭即销毁窗口”“隐藏页也已创建所有控件”的断言，改为验证窗口已关闭、页面首次选择后数据正确，以及输入输出和存储结果。测试使用真实兵种目录、真实人员结果夹具和临时 SQLite 库；所有 Tk 操作运行在私有 Windows 桌面。

## 实际 EXE 验证口径

优化前的游戏目录版本保存在 `.tmp/ui-lazy-before.exe`。新旧版本使用 `.tmp/ui-profile-data` 固定副本交替各运行三轮；正式计时期间不并行运行单元测试或构建。原始结果为 `artifacts/ui-performance/lazy-final-{before,after}-{1,2,3}.json`，汇总为 `lazy-final-summary.json`。

新版历史首次打开以左侧轮次卡片和右侧视口中的可见结果都完成为就绪条件，不以空窗口出现为完成。另测滚动到最后一项、回到顶部，以及真正关闭/再次打开的缓存路径。旧版没有视口和缓存路径，旧版规则再次打开是重建；新版规则再次打开是复用。这是产品行为变化，需与新进程首次打开分开解读。

私有桌面验证实际 EXE 的控件创建、布局、回调及可见内容就绪，不验证交互桌面的 DWM 帧率、真实鼠标手感或游戏负载下的竞争。新进程首次打开不等于操作系统冷缓存。

中间方案的左侧轮次视口加载实测将上一页中位耗时从 135ms 增至 223ms，因此未采用。该方案三轮报告保留在 `lazy-{before,after}-{1,2,3}.json`，不可当成最终版本结果。最终针对性回归 90 项通过，覆盖规则、历史、简单难度、特殊/高阶规则和结果图选择。

最终完整单元测试 854 项通过（261.2s）。最终 EXE 通过四项标准打包冒烟检查，SHA-256 为 `71E70313D509067A90B3B7B2B72D3A8A51D5CF69D7C55A91FC46F1D3DBFA7DBA`；仅写入项目 `dist`，未覆盖游戏目录。

## 最终三轮结果

六份报告均为实际打包运行（`frozen=true`），状态全部通过，无回调错误；旧版每轮 45 个场景，新版每轮 52 个场景。下表为内容就绪耗时的三轮中位数，单位 ms。

| 操作 | 旧版 | 新版 |
| --- | ---: | ---: |
| 历史首次打开 | 776.3 | 576.2 |
| 历史下一页 | 442.1 | 212.3 |
| 历史上一页 | 137.8 | 113.0 |
| 历史正常关闭后再次打开 | 746.3（重建） | 184.4（复用） |
| 规则首次打开 | 416.9 | 364.2 |
| 规则正常关闭后再次打开 | 416.7（重建） | 111.9（复用） |
| 统计首次打开 | 405.0 | 332.7 |
| 历史详情打开 | 609.1 | 411.1 |
| 空间清理打开并扫描 | 370.2 | 560.6 |

历史下一页最大心跳间隔中位数由 81.4ms 降至 20.5ms，首次历史由 130.1ms 降至 85.3ms。首次打开高级模式约 85.8ms，高级子页首次选择为 0～91.9ms。

本轮没有全部达到 300ms：历史、规则、统计首次打开，以及历史详情和空间清理仍超标。空间清理三轮新版为 577.2、560.6、341.7ms，旧版为 336.9、372.4、370.2ms，本轮对照表现变慢，原因尚未定位，不能宣称所有弹窗均有改善。缓存重开结果也不能代替首次打开结果。后续若继续以全场景低于 300ms 为目标，需要继续单独拆解上述路径。
