# ST-007 历史管理与数据导出

## 目标

提供统计历史的查看、清理、重建和导出能力。

## 功能

- 查看指定运行。
- 查看指定轮次。
- 删除指定运行。
- 清空统计历史。
- 从已有快照重新生成统计。
- 导出 PNG、CSV、JSON。

## 关键规则

- 删除和清空必须二次确认。
- 清空统计不删除游戏存档。
- 清空统计不删除 `randResult`。
- 清空统计不删除原始日志和诊断日志。
- CSV 和 JSON 必须包含当前筛选条件。
- JSON 导出保留完整结构化快照。
- 规则汇总或分组导出必须保留 `rule_snapshot_hash`、规则 schema 版本和筛选条件。
- PNG 导出当前图表视图。

## 验收标准

- 删除一个运行不影响其他运行。
- 清空后统计投影为空或被隐藏，但结果快照、存档、结果图和日志仍存在。
- 清空后可以从结果快照重新生成统计。
- 导出结果与当前页面筛选结果一致。
- 无数据或校验失败时导出行为有明确提示。
- 导出的存档数、状态数和页面总览一致，不能把重复尝试导出成重复存档。
