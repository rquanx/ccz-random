# 内置游戏补丁资源

这两个文件用于工具“常见问题”中的补丁安装功能，是正式打包依赖，不是构建缓存。

| 文件 | 用途 | SHA-256 |
| --- | --- | --- |
| `growth-fix.zip` | 吃桃补丁，包含替换用 `Ekd5.exe`、`CCZFX.DLL` 和说明 | `2a375385b1c26be4245694539f6bf6f3435821f9d1289e05e693252e9c645706` |
| `Ekd5-audio-fix.exe` | 音效卡顿修复的独立游戏启动器 | `5bb66f71f7641da63473f9cd730dfbc37886ac448657ae61e87fbc86da734b32` |

吃桃补丁压缩包体积约 44 MiB，主要是必须随补丁分发的游戏 EXE。安装服务会分别校验包内 EXE 和 DLL；具体校验值保存在 `ccz_randomizer/growth_patch.py`。

吃桃补丁的原生源码和构建入口位于 `native/`，完整隔离副本的制作工具位于 `tools/research/build_growth_exe_prototype.py`。补丁原理、备份还原与已验证场景见 [补丁调查文档](../../docs/patches/)。音效启动器由用户提供，不能仅靠本项目源码重新构建。

替换任何资源时，需要同步更新对应服务的校验值并运行补丁安装、重复安装、备份还原及异常恢复测试。不要把游戏完整目录或个人存档放进这里。
