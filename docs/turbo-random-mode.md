# 极速随机模式

运行参数中的“极速模式”位于“兼容模式”后，同一行，默认关闭。悬停提示为“更快的随机，但可能会导致 bug。”勾选状态自动保存，启动后传递到各个 Worker；随机运行期间开关禁用，结束后恢复。

## 执行方式

常规模式保持原有读档、场景等待和点击时序。极速模式使用独立的 `runtime/turbo.py` 策略：复用游戏实例读档后的场景等待从 1000 ms 缩短到 50 ms，NPC 和选项分别使用 100 ms 短脉冲输入，NPC 后等待 50 ms。首轮标题读档仍保留原来的 1500 ms 场景等待。

`runtime/normal_random.py` 独立维护常规点击与等待；`runtime/turbo.py` 独立维护短脉冲和稳定性确认。`runtime/random_interaction.py` 仅负责策略选择和当前实例内的单向回退。游戏适配器不再包含极速专属的点击、等待或结果轮询分支；未开启极速时，不构造极速策略，也不执行其版本判断或内存稳定性读取。两个实例各自持有策略对象，互不修改状态。

随机仍由游戏自身执行，不自行生成或改写兵种、特技结果。结果变化后，连续两次完整源存档内存区域读取一致才进入评分；保存使用原有游戏菜单及校验流程。

极速交互没有触发随机时，当前游戏实例关闭极速策略，恢复场景等待和常规交互；之后的轮次也保持常规时序。结果已经变化但尚未稳定时，不输出或保存该候选，交给现有失败恢复流程重新读档。停止请求始终向上传递。

短脉冲时序目前针对 `2.20-1104-night` 验证，其他布局回退常规策略。兼容模式控制实例刷新，极速模式控制交互策略，两者可同时选择；多实例通过环境变量继承设置。

直接原生读档的试验未通过完整源存档校验，未接入正式策略。本次不修改原生 C 源码，不增加新的注入动作。

## 策略隔离回归

新增 7 项独立性测试，覆盖常规模式不构造极速策略、不读取极速稳定快照、原有点击尾部等待及 3 秒确认上限、单实例回退不影响其他实例、禁用策略不可再次进入，以及停止请求。完整 679 项单元测试通过。

隔离后在临时游戏副本中验证常规 3 轮（重复中位 4442.5 ms）、极速 5 轮（重复中位 2618.65 ms）、丢弃首次 NPC 输入后 3 轮正常恢复，以及 3 个结果存档分别重启游戏读取、全人物快照一致。除了故障注入产生的一次预期回退，其他测试没有交互重试。

本次证据为 `isolation-targeted.txt`、`isolation-full-unit.txt`、`isolation-normal.json`、`isolation-turbo.json`、`isolation-retry.json`、`isolation-save.json`。
