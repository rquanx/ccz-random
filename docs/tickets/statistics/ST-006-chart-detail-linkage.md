# ST-006 图表、筛选和明细联动

## 目标

让统计窗口从静态展示变成可追溯的结果分析工具。

## 交互

- 点击状态饼图区域，筛选对应状态。
- 点击失败原因柱，筛选对应失败原因。
- 点击兵种、特技或宝物柱，显示关联存档。
- 点击趋势节点，显示对应日期或轮次。
- 点击武将，查看该武将的兵种、特技和宝物。
- 点击存档，打开评分详情。
- 点击结果图入口，打开对应结果图。

## 明细字段

```text
运行时间
轮次
存档编号
武将
兵种
个人天赋
兵种技能
宝物
宝物特性
最终状态
尝试次数
```

## 验收标准

- 图表点击后明细表同步过滤。
- 清除图表过滤后恢复顶部筛选结果。
- 点击未知项可以定位到具体结果。
- 点击存档不会丢失当前筛选条件。
- 详情和结果图使用相同的快照 ID。
