# 首次使用询问与新手引导

## 行为

首次提示保留原来的 5 秒阅读等待，在同一弹窗增加是否第一次使用的选择。等待期间即可选择；没有默认答案，必须等倒计时结束且选定答案才能继续。选择“是”后按钮显示“开始新手引导”，选择“不是”显示“进入工具”。只有继续时写入原有的本机已读标记，提前关闭不写入，计时器随窗口关闭取消。保留原有状态保存失败的提示。

新手引导使用主窗口范围内的聚光灯蒙层和浮动卡片，不再插入主界面布局，分六步介绍准备来源存档、选择规则、设置运行参数、开始与停止、找到并使用结果、帮助与特效说明入口。无关区域以半透明蒙层压暗，对应的真实控件镂空显示并以蓝色细框标出；同一步的多个入口分别标出，不用一个大框包住整片无关区域。支持上一步、下一步、跳过及完成，每一步显示进度，可按 Esc 退出；查看完整使用说明会先结束引导，再打开说明，避免蒙层遮挡帮助窗口。引导使用本地模态占用防止误点开始随机，跳过或完成后解除，不设置全桌面置顶。卡片优先放在目标下方或上方，避开目标且限制在主窗口内，随移动缩放更新，最小化时一起隐藏。引导不会启动随机、修改规则、改变并发和循环选择或操作真实游戏。

“常见问题 → 新手引导”可随时重看，重看先关闭维护菜单并释放它的模态占用，回到真实主界面。重复打开只保留一份引导，关闭时清除边框、布局回调和事件订阅。原来已经确认过首次提示的用户不会重新遇到强制倒计时，可直接从常见问题重看。

最小窗口宽度下缩短规则下拉框，避免主操作按钮被挤窄；正常宽度继续使用原来的下拉框宽度。默认窗口和 760×520 的主界面均检查六步内容、导航和目标标记。

## 使用说明审阅

原说明覆盖了大部分功能与边界，但偏向功能参考，缺少清晰的第一次使用路线。“快速开始”调整为四个实际步骤：

1. 工具放在哪里、在什么时机准备第20栏来源存档、哪里看位置图。
2. 在哪里选规则，第一次使用单实例且不循环，内置规则通过“新建副本”修改。
3. 点哪个按钮开始、依赖检测不通过怎么办、进度与严格筛选的等待、如何停止。
4. 图片、历史详情和游戏存档分别在哪里，如何根据槽位回游戏读档、旧轮次如何导出，统计为何不等于存档列表。

另明确使用说明、新手引导、规则说明、特效手册、故障检测和清理各自的入口。详细功能说明和使用注意继续保留。关闭从常见问题打开的使用说明时，恢复父菜单的模态占用。

## 验证范围

使用真实 Tk 控件及实际主窗口的入口，隔离本机偏好文件，模拟倒计时回调验证五个一秒周期。覆盖等待中选择不能跳过倒计时、未选答案不能继续、新手与熟练用户分支、保存失败、提前关闭、不启动随机及不修改设置、六步往返与完成、跳过、重看、关闭主窗口和帮助模态恢复。

视觉检查和流程烟测在独立 Windows 桌面进行，不切换用户桌面、不占用鼠标键盘，不启动游戏、不上传文件。源码的单次引导测量仅用于检查新增布局和翻步开销，不作为打包 EXE 的性能保证。游戏内的许子将操作和读档步骤依据已有业务流程说明，未在本轮启动真实游戏验证。

## 本轮结果

- 完整单元测试 892 项通过，321.960 秒（`.tmp/onboarding-full-unit.log`）。其后最后的布局及关闭回归由 31 项针对性测试覆盖，全部通过，7.962 秒（`.tmp/onboarding-targeted-latest.log`）。
- 默认尺寸及 760×520 的真实主界面完成六步视觉检查，包含首次询问、目标边框、最小宽度下完整的开始按钮、导航与清理；截图在 `artifacts/ui-performance/onboarding-*.png`。
- 主窗口源码后台流程验证通过，无回调错误。新增引导的九个操作中，打开 170.29ms、重看 154.53ms、翻步 54.36～277.24ms、跳过 94.94ms，单轮均低于 300ms。此处为源码诊断，不代表 EXE 性能保证（`artifacts/ui-performance/onboarding-source-smoke.json`）。
- 已读标记沿用原有机制，不强制已使用过的用户重复首次提示。本轮没有重新打包 EXE，也没有覆盖游戏目录的发布文件。

最新针对性测试 19 项全部通过（20.623 秒），包含负坐标窗口定位回归；日志 artifacts/onboarding-spotlight-tests.log。最终保持版本 4.1，更新使用说明及版本说明。
