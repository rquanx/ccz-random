# 游戏名称核对（2.20-1104 夜版）

人物特技、兵种天赋和宝物能力后缀以游戏的最终格式化输出为准。基础名、格式类型和参数不能单独当作完整名称，也不能据参数自行解释效果。

## 已确认的问题

- 编号 84 的基础名为“弱点攻击”，格式 8、参数 6。游戏只对参数 1～5 显示“攻击／防御／精神／爆发／士气”，其他值不显示后缀。因此正确名称是“弱点攻击”，不能写成“弱点攻击 移动”。
- 格式 6 的源能力超出五项战斗能力范围时，游戏回退到攻击，工具原先可能显示移动或数字。
- 格式 7 的策略名称为空时，游戏不显示策略后缀，工具原先会显示参数编号。
- 宝物的 HP／MP 辅助、忽视能力按五位掩码，提升周围和自动提升按六位掩码。原先只列了少量组合，会遗漏合法组合或带入不该显示的移动位。
- 宝物能力辅助和能力替换原先只列了少量参数，现按游戏的源能力和目标掩码完整解析，以 `→` 显示关系。

当前 240 项规则目录中需要改名的是编号 84；255 条运行时定义（包含保留项）均已核对。4.0.1 的默认数据包为 v2/r5。能力标签、格式模板、参数范围、位掩码宽度、能力转换规则、名称别名及宝物效果均保存在 `skills.json` 的 `nameFormatting` 和 `displayRules` 中。引擎只执行经过校验的声明式操作，不执行数据包中的代码；旧 v1 包由 4.0.0 继续使用，不在新版回退硬编码中文表。

旧名称的自定义评分和类型通过名称别名保留；精确的新名称优先。历史期望文本中源自旧解析器的错误名称已修正，原始采集内存字节未修改。线上 OSS 未随本地构建自动发布。

## 证据和复验

`tests/fixtures/skill_display_1104.json` 记录真实游戏二进制 SHA256、能力表、策略名及原生函数的输出。工具只在隔离桌面启动临时标题进程，读取内存后退出，不读写存档。原始 x86 函数在 Unicorn 中执行，不向游戏注入或修改代码；唯一外部调用 `wsprintfA` 用等价字符串输出替代。

- 人物／兵种：`0x418D97` → `0x428373`。
- 宝物能力后缀：`0x460509`。
- 能力辅助／替换：`0x423D2C`、`0x423D47`。

运行诊断（Unicorn 是可选的开发依赖，不加入 EXE）：

```powershell
.\.venv-win10-py314\Scripts\python.exe -m tools.diagnostics.audit_skill_display --game 'E:/game/ccz/曹操传加强版v2.20-1104夜/Ekd5.exe' --output artifacts/skill-display.json --unicorn-path .tmp/name-audit-deps
```

快速回归不依赖游戏或模拟器：

```powershell
.\.venv-win10-py314\Scripts\python.exe -m unittest tests.unit.test_game_skill_display
```

分别验证标题阶段真实参数、规则目录配置参数，避免把随机前后参数不同误判为命名错误；额外覆盖 8 类宝物能力后缀的全部 256 个字节参数。
