# ST-004 统计窗口框架与总览 Tab

## 目标

增加统计窗口和统一筛选器，先交付总览能力。

## 界面

顶部筛选器：

```text
统计范围：当前运行 / 当前轮次 / 全部历史
数据口径：最终结果 / 全部已完成 / 全部尝试
随机模式：全部 / 3 人 / 7 人
规则配置：当前规则 / 指定规则 / 全部规则汇总 / 全部规则分组
存档范围：全部 / 单个存档 / 存档区间
武将：全部 / 指定武将
时间：全部 / 今天 / 本周 / 本月 / 自定义
```

总览内容：

- 统计存档数、已完成数、合格数、不合格数。
- 异常数、已停止数、未完成数。
- 合格率、总尝试次数、平均尝试次数。
- 状态分布图。
- 失败原因图。
- 存档明细表。

## 关键规则

- 默认打开时使用“全部历史 + 最终结果”。
- 规则配置默认使用“全部规则汇总”。
- 筛选器变更后所有统计内容同步刷新。
- 页面显示当前数据口径和统计范围。
- 页面显示规则名称、规则版本和配置指纹。
- 默认“全部规则汇总”明确显示“跨规则汇总”，并显示规则数和样本数。
- “指定规则”支持选择一个或多个规则配置；“全部规则分组”按规则分别展示。
- 无当前运行上下文时，当前运行/当前轮次筛选项不可用并给出原因。
- 技术运行信息不显示在统计窗口。

## 验收标准

- 可以从主界面打开统计窗口。
- 所有筛选器至少可用：范围、口径、模式、规则、存档、武将、时间。
- 汇总数字与查询服务结果一致。
- 已停止和未完成不会被误显示为不合格。
- 窗口可以在无历史数据时正常显示空状态。
- “全部规则汇总”显示跨规则汇总标识、规则数量和样本量。
- “全部规则分组”显示独立规则分组和样本量。
- 跨规则汇总不作为规则概率对比结论。
- 已完成数、状态数和平均尝试次数按存档任务去重。
- “全部已完成”和“全部尝试”时，页面明确区分总览去重数字与尝试级明细，
  避免用户把失败原因次数当成存档数。
