### 沙箱规则文件隔离问题

首次真实 WPF UI 测试发现 JSON 配置被硬链接，测试对副本的写入影响了原 `random_rules_v2.json`。已从本会话迁移前的完整读取输出核对原配置与保留的 `random_rules.json` 语义完全一致，随后使用保留文件原始字节恢复新规则文件；恢复后 SHA256 为 `c86dd4176b7c5c1d51090b52d164f4181d49051eb0fe16596865e9560e8d9a59`。证据保留于本地 artifacts，不作为默认配置发布。

修复：JSON/JSONL/数据库/备份文件在根目录及子目录全部独立复制；新增嵌套沙箱写配置不影响上游的回归。之后两次真实界面测试均通过原目录所有 JSON/存档哈希保护校验。原游戏存档未受到此问题影响。
