# 输入与选择控件

共用控件只负责外观、选中、键盘与弹层生命周期，业务模块决定何时应用或保存。

| 场景 | 控件 | 应用方式 | 最近关键词 |
| --- | --- | --- | --- |
| 入队人员、宝物 | SearchEntry + SearchMemory | 即时过滤；停顿 1 秒记录有效关键词 | 各自独立的 10 条 LRU |
| 兵种天赋、人物分页、评分卡片 | SearchEntry | 即时过滤；空格分词匹配 | 不额外增加 |
| 历史查询 | SearchEntry | 回车或搜索按钮应用，与时间范围一起查询 | 不额外增加 |
| 数字、名称、日志地址 | TextEntry | 保留原有校验和提交方式 | 不记录 |
| 日期与时间 | TextEntry + 原日期时间选择器 | 保留原有范围校验与确认方式 | 不记录 |
| 关卡 | SearchableCombobox | 弹层搜索，选择后应用 | 不记录临时搜索词 |
| 规则、人数、倾向等 | SelectionCombobox | 10 项及以内直接选择，超过 10 项提供搜索 | 不记录临时搜索词 |
| 卡片内分数及类型编辑 | 紧凑样式的 TextEntry / SelectionCombobox | 原有回车、失焦提交，Esc 取消 | 不记录 |

- 输入框统一字体、内边距及 Ctrl+A 全选。只有搜索框的 Esc 会清空非空查询；空查询继续交由窗口处理 Esc。
- 搜索弹层支持方向键、Enter / 数字键盘 Enter 选择、Esc 取消、Tab / Shift+Tab 离开。取消和离开不改变已选值。
- 弹层先关闭并恢复原模态抓取，再通知业务模块处理选择；禁用、替换选项和销毁时关闭旧弹层。
- 鼠标滚轮经过收起的下拉框时不改变已有选择。
- 关键词记录不抢焦点，不记录空值和无结果输入；连续补全只合并本次新记入的前缀。
- 记录定时器与变量监听随搜索框销毁清理。卡片内采用紧凑内边距，避免固定高度裁切文字。

回归测试：`tests/unit/test_input_controls.py`，以及各模块已有的真实 Tk 交互测试。数据与游戏流程的回归继续由完整单元测试覆盖。
