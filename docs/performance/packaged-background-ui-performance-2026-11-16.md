# EXE 后台界面性能验证（2026-11-16）

本次新增显式诊断入口 `--benchmark-ui`，将测试流程打包进真实 PyInstaller EXE，随后在 3 个新启动进程中执行。正常启动不启用该入口。没有使用外部鼠标、键盘输入，不切换当前桌面；Windows 子进程使用 `tests.helpers.desktop.background_desktop` 创建的私有桌面。测量报告含 `frozen: true`、EXE 路径、SHA-256 及各轮实际私有桌面名称。

验证的是本地重新打包的诊断构建，新增部分是测试入口和诊断模块；各弹窗仍使用真实主界面按钮绑定的产品实现。这不是之前游戏目录中 BAFEA38D… 那份文件的逐字节验证。诊断构建 SHA-256：`03E1B2F2C9A7D45330AC235610DAF39ECFD246E0B0334255C94A550EE1451C82`。本轮没有替换游戏目录中的 EXE。

## 数据与隔离

通过 SQLite 只读连接备份真实历史和统计库到临时目录，复制规则文件；后续窗口仅访问副本。样本为 4,150 次随机、61 个历史轮次、356 项宝物效果频率、204 项特技频率、302 项手册条目。没有启动游戏、执行随机、删除数据、上传日志或检查网络更新。运行真实主界面及其启动特技目录预加载；仅关闭首次使用提示、联网更新和游戏定位，保持测试可重复。没有修改真实规则和统计。

## 覆盖及结果

每轮 45 项操作，3 轮 135 项全部通过，Tk 回调异常为 0。

- 统计首次打开、两次重新打开；原生下拉及搜索下拉打开/关闭；人物、宝物页首次加载和返回已加载页；结果筛选；特技和宝物频率滚动。
- 历史首次打开、重新打开、卡片就绪；下一页、上一页；规则筛选及重置；存档详情打开。
- 规则设置首次/重复打开及两个外层页签切换。本数据下人物列表没有可用的下一页，故未执行规则人物分页，不能把它列为已覆盖。
- 特效手册打开、选择末项、搜索、重新打开；常见问题；使用说明 11 个页签；空间清理窗口及扫描（不执行清理）；确认弹窗取消并核对返回值。

| 操作 | 就绪耗时范围 | 三轮中最大心跳间隔 |
| --- | ---: | ---: |
| 统计首次打开 | 353–421ms | 129ms |
| 统计人物页首次加载 | 183–248ms | 149ms |
| 统计宝物页首次加载 | 236–294ms | 146ms |
| 统计结果筛选 | 190–206ms | 121ms |
| 特技频率滚动 | 15–27ms | 23ms |
| 宝物频率滚动 | 56–70ms | 64ms |
| 历史首次打开 | 723–1047ms | 139ms |
| 历史下一页 | 349–600ms | 71ms |
| 存档详情打开 | 457–591ms | 233ms |
| 规则设置首次打开 | 421–552ms | 293ms |
| 特效手册首次打开 | 159–171ms | 75ms |
| 空间清理打开并完成扫描 | 342–473ms | 177ms |

时间由 EXE 内部测量，不包含 UI 自动化截图开销。command_ms 是按钮命令返回耗时；ready_ms 包括异步查询、回调和一次 Tk 更新至目标状态；另连续观察 120ms 的延后绘制，用 8ms 心跳记录事件循环停顿。135 项是三次同组流程，不能当成 135 种独立功能。

结论：本次没有复现统计首次打开 5～6 秒。历史读取仍需要接近 1 秒；规则设置和详情构建有约 0.23～0.29 秒的事件循环停顿，仍有可感知的优化空间。不能笼统判定所有操作性能没有问题。

## 测试边界

私有桌面测试验证实际 EXE 中的 Tk 控件创建、应用命令、异步数据加载及事件循环响应；不验证当前交互桌面上的鼠标手感、DWM 合成帧率、显示器缩放切换或游戏运行时的资源竞争。缓存状态未经人为清除，因此“首次”指新进程中首次打开，并非操作系统冷缓存。

详情的计时目标是详情窗口出现，随后继续观察 120ms；没有逐项验证详情中所有分批人物卡片已经完成。首次加载历史后卡片另有就绪检查，统计详情结果与真实仓库查询结果对照。规则页签测试不执行保存；确认弹窗使用诊断文案，避免对用户数据产生副作用。

原始报告：`artifacts/ui-performance/packaged-background-1.json` 至 `packaged-background-3.json`；汇总 `packaged-background-summary.json`。打包日志 `.tmp/build-background-ui-benchmark.log`，4 项标准 EXE 冒烟测试通过。
