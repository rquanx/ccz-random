# ST-005 兵种、特技、宝物分布 Tab

## 目标

实现三个业务分布页面，展示用户最终随机结果的内容分布。

## 兵种分布

- 横向柱状图。
- 出现次数、占比、覆盖存档数、覆盖武将数。
- 支持按武将、存档、随机模式查看。
- 显示武将位置分母。

## 特技分布

个人天赋和兵种技能必须分成两个子 Tab：

- 个人天赋：逐项计数、覆盖武将、覆盖存档、多天赋组合。
- 兵种技能：逐项计数、覆盖兵种、覆盖武将、覆盖存档。
- 额外显示有/无个人天赋、有/无兵种技能。

## 宝物分布

- 宝物名称。
- 宝物特殊特性。
- 真实识别到的套装或特殊组合。
- 无组合时显示“本次没有识别到套装组合”。

## 验收标准

- 多天赋不会合并成单个字符串或只保留第一项。
- 3 人和 7 人的比例可直接比较且分母明确。
- 未知项作为独立类别显示。
- 不显示没有实际数据的“特殊组合”空栏目。
- 每个图表的次数和比例来自同一筛选结果集。
- 全部规则汇总视图显示跨规则汇总标识和包含规则数量。
- 全部规则分组视图按规则独立计算次数、比例和分母。
